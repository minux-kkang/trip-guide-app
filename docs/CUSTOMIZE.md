# Customize Guide

## Sample과 Template의 역할
- `/sample-singapore-2026`: 실제 여행에서 어떻게 쓰였는지 보는 완성 예제
- `/template`: 다음 여행을 시작할 때 복사하는 코드

## 권장 방식
새 여행마다 template 폴더를 복제해 별도 repo 또는 별도 폴더로 사용한다. 싱가포르 샘플은 수정하지 않고 reference로 남긴다.

## UI 원칙
1. 첫 화면에는 DAY, 시간, 제목만 선명하게
2. 예약/교통/상세정보는 한 단계 안쪽
3. 계획↔실제 비교는 평상시 숨기고 필요할 때 연다
4. A/B 팀 분리는 해당 시간대만 2열, 합류 후 다시 1열
5. 모바일 우선
