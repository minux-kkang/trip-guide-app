# Singapore 2026 Reference Sample

실제 11명 가족여행 중 사용한 앱을 정리한 **reference sample**입니다.

## 이 샘플에서 볼 것
- DAY별 계획/실제 기록
- 오전 A/B 팀 분리 후 합류하는 일정
- 예약/교통/영어/준비 도구
- 최초 계획을 삭제하지 않는 비교 아카이브
- 일정 변경 사유 기록
- 쇼핑·선물·먹거리·여행 팁 확장 예시

## 상태 원칙
- `originalPlan`: 최초 계획. 수정/삭제하지 않음
- `revisions`: 중간 변경 이력
- `currentPlan`: 현재 운영안
- `actualRecord`: 실제 진행 결과
