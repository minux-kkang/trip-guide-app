# Family Trip App · Sample & Template

가족여행을 **계획 → 현장 운영 → 실제 기록 → 회고**까지 연결하는 정적 HTML 여행 앱입니다.

## 폴더
- `sample-singapore-2026/` : 2026 Singapore Family Trip 실제 사용 reference sample
- `template/` : 다음 여행에 복제해서 쓰는 범용 starter
- `docs/` : 데이터 모델과 커스터마이즈 가이드

## 핵심 컨셉
> 겉으로는 여행 팜플렛처럼 쉽고, 안쪽에는 실제 여행 도구와 기록이 모두 들어있다.

### 계획은 지우지 않는다
```text
Original Plan → Revision History → Current Plan → Actual Record
```
실제 기록이 업데이트되어도 최초 계획을 보존하므로 여행 후 **계획 대비 실제**, **변경 이유**, **다음 여행 개선점**을 비교할 수 있습니다.

## GitHub Pages
repo root를 Pages로 배포하면 `index.html`에서 Sample과 Template 중 선택할 수 있습니다.
